# FFmpeg 工具链

SagaFlow 只通过子进程调用 `ffmpeg` 和 `ffprobe`，不会链接 FFmpeg
库，也不会把第三方二进制放进应用或发布归档。

## 运行时发现

SagaFlow 按以下顺序查找成对的可执行文件：

1. 数据目录下的托管工具区 `data/tools/ffmpeg/`；
2. SagaFlow 可执行文件所在目录；
3. 当前工作目录；
4. 系统 `PATH`。

Windows 使用 `ffmpeg.exe` 和 `ffprobe.exe`，其他系统使用无扩展名文件。
因此开发时仍可把自己的工具链放进已忽略的 `bin/`，或直接使用系统包。

## 安装方式

工具页在未发现完整工具链时提供三种方式：

1. **直接下载**：应用直接连接固定下载源；
2. **代理下载**：通过 `127.0.0.1:<端口>` 的本机 HTTP 代理，可选填写
   Basic Auth 账户和密码；这些信息只在本次内存任务中使用，不会持久化；
3. **手动下载**：界面显示当前系统架构对应的链接、SHA-256、文件名和最终
   放置目录，复制 `ffmpeg` 与 `ffprobe` 后可立即重新检测。

下载在后台继续，切换页面不会中断；工具页会显示实时字节数、速度、预计
剩余时间和阶段，并可在下载或解压前取消。安装器只使用源码中固定的 HTTPS
地址、文件大小和 SHA-256；文件先下载到数据目录内的随机临时目录，校验并
执行 `ffmpeg -version` 成功后，再原子移动到托管工具区。网络中断会在同一
临时文件上有限重试，应用下次启动会清理遗留的未完成安装目录。

当前固定资产如下：

| 平台 | 固定版本 | 下载来源 |
| --- | --- | --- |
| Windows amd64 / arm64 | 8.1.2 | BtbN/FFmpeg-Builds `autobuild-2026-06-30-13-34` |
| Linux amd64 / arm64 | 8.1.2 | BtbN/FFmpeg-Builds `autobuild-2026-06-30-13-34` |
| macOS amd64 | 8.1.2 | evermeet.cx 固定 release 包 |
| macOS arm64 | 8.1.2 | Martin Riedl 固定 release 包 |

升级固定资产时必须同时更新源码中的 URL、字节数、SHA-256 和测试矩阵。
这些来源只负责提供 FFmpeg 构建，SagaFlow 不会把下载文件加入自身源码或发布包。

源码使用 GNU Affero General Public License v3.0（`AGPL-3.0-only`）；
用户触发下载后，工具目录会写入来源和 FFmpeg 许可页面链接。重新分发第三方
二进制时，分发者仍需独立满足对应构建的许可和源码义务。
