# 个人版架构

## 目标

SagaFlow 个人版面向单个创作者自己的电脑、NAS 或私人服务器。它保留登录保护和完整生产能力，但不承担团队版的用户、角色、工作组、权限、配额和审计边界。

## 运行模型

```text
浏览器
  │ HTTP / Cookie
  ▼
SagaFlow 单二进制
  ├─ Fiber API + 内嵌 React
  ├─ 业务服务与推理网关
  ├─ SQLite 持久任务队列
  ├─ SQLite 元数据
  └─ 本地内容寻址对象目录
       └─ 手动发布到可选 S3 连接
```

API 与任务执行位于同一进程，但任务状态不是内存状态。任务提交后先写入 SQLite，worker 使用带租约的原子领取；异常退出时正在执行的任务会标记为 `interrupted`，不会假装已经完成。全局并发数由运行配置控制，Ollama/ComfyUI 连接还可以保存自己的并发上限。

## 数据目录

正式二进制默认把数据写入自身同目录的 `data/`；`go run` 会退回当前工作目录，避免把数据写进 Go 的临时构建目录。Docker 和 systemd 部署分别显式使用 `/data` 与 `/var/lib/sagaflow`，也始终可以用 `SAGAFLOW_DATA_DIR` 或运行配置覆盖。

```text
data-dir/
├─ sagaflow.db       # SQLite 元数据、内部配置、任务与调用记录
├─ objects/          # 本地素材主副本，按 SHA-256 内容寻址
├─ temp/             # 原子写入和临时处理
├─ secrets/
│  └─ master.key     # 数据库中模型/S3 凭证的加密主密钥
├─ backups/          # 默认备份输出
└─ config.yaml       # 可选的少量运行参数，不进入可迁移备份
```

逻辑素材记录与物理文件分离。相同内容只需要一份物理文件，不同素材仍有各自的业务记录。删除逻辑记录不会贸然删除可能仍被其他记录引用的物理字节，后续可由显式压缩/清理工具回收。

## 单账号安全边界

- 数据库结构使用单例约束，物理上不能创建第二个账号。
- 会话令牌是随机不透明值，数据库只保存 SHA-256 摘要；会话可撤销。
- 密码由最新版 `github.com/gofurry/easyhash` 处理，登录时自动升级旧哈希参数。
- 默认只监听 `127.0.0.1`。监听非回环地址时，启动前必须已经初始化账号。
- 模型与 S3 凭证用随机主密钥加密后存入 SQLite；运行配置不承载业务凭证。

单账号登录防止 NAS 或私人服务器直接暴露工作台，但它不等同于多租户隔离。需要多人协作、细粒度权限或组织审计时应使用团队版。

## 模型边界

推理网关只接受统一的请求、输入流、参数与产物，不依赖 Fiber、SQLite 或项目领域。服务连接、模型目录、参数 schema、凭证和工作流模板存储在 SQLite，新增 Ollama 模型通常由发现结果自动生成通用 schema；ComfyUI 使用导入助手分析 API 工作流并生成绑定与输出选择器。

Prompt 预设和音色档案属于整个本地工作台，不跟随单个项目创建或删除。音色档案保存模型无关的参考素材或设计描述，具体远端音色通过模型绑定表管理。新数据库会预置本机 Ollama 与 ComfyUI 的标准连接地址；离线只表示当前未检测到服务，不影响工作台其他功能。

本地 Adapter 直接消费本地对象流：

- Ollama：文本与支持视觉输入的模型；
- ComfyUI：工作流输入先通过本地 ComfyUI 上传接口传递。

云端 Adapter 如果需要参考文件，只接受已经手动发布的 `asset_remote_export`。后端会再次校验远端副本属于该资产，并在调用时生成短期签名 URL。

## S3 边界

S3 不是主存储，也不参与普通上传或生成结果入库。它只提供一个显式的“发布副本”动作：

1. 用户在设置页保存一个 S3 兼容连接；
2. 用户对具体资产选择发布目标；
3. SagaFlow 从本地主副本上传并记录远端对象；
4. 云模型生成时可选择该远端副本；
5. 用户可以显式删除远端副本。

腾讯云 COS、阿里云 OSS、MinIO 都通过 S3 兼容协议接入，不在核心中维护厂商专用存储实现。

## 不包含的兼容层

个人版不读取团队版的 PostgreSQL 数据、Redis 队列、工作组归属、角色权限、对象存储注册表或旧配置。团队版代码和迁移历史保留在独立仓库；个人版保持一套可理解、可演进的干净模型。
