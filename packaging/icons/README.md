# Application icons

These are the text-free SagaFlow application icons used by platform packages.

- `windows/sagaflow.ico`: Windows executable and shortcut icon.
- `macos/sagaflow.icns`: macOS application bundle icon.
- `linux/hicolor`: freedesktop-compatible application icon hierarchy.

The Web UI uses `web/public/logo-mark.png`, while the full colored wordmark is
stored at `web/public/logo.png`.
